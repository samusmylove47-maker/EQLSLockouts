**The lower bound is a REFUSED hail, not a completion, and that matters.** A
refusal is direct evidence the old period was still running at that instant. It
is stronger than the completion-based bound *and it does not depend on the
3-per-week cap at all* — see §6, where the cap turns out not to carry the weight
two separate arguments put on it.

**Also measured: a floor on the period.** The last weekly was granted Tue 11 Aug
22:38 and was still refused on **Sun 16 Aug 22:20 (Avenrae, ≥4.99 days)** and
**Mon 17 Aug 17:25 (Shara, ≥5.78 days)**, Voidling present as control, no grant in
between. **Any cycle of 24 hours, or of anything up to 5.78 days, is refuted by
measurement.** That is a real exclusion and it is ours.

**What the bracket does not do:** 26 hours spans parts of Monday and Tuesday, so
it does not distinguish a Tuesday-morning reset from a Monday-evening one.

**One thing I found inside the bracket, and I am flagging it as Tier 5 rather
than leaning on it.** In our own log, on the day, someone asks the question

**The four things that would actually bite, in order:**

1. **`logWatcher` never replays history — it starts at end-of-file by design**

   reset bracket needs two grants that may be days apart. Dropped in as-is it

2. **The watcher follows whichever `eqlog_*.txt` changed most recently**, so it

   history fabricated reset brackets *four seconds wide* when I first ran it. My
   core now **requires** a character at construction and refuses to be shared;
   `characterFromLogFilename()` does the routing parse.
3. **A latent multibyte defect in her tailer, offered as a gift, not a
   complaint.** `_pollActiveFile` opens a fresh `createReadStream` at a byte
   offset with `encoding: 'utf8'` on every 200 ms poll. If a multi-byte character

   lost something. Reading the tail as a `Buffer` and decoding after joining

4. **She has no timezone anywhere either.** My core refuses to accept a `Date` or

### 6. Where the prompt and the brief are wrong

Twelve. Several are load-bearing.

1. **The search string in my own brief is wrong.** It says grep for
   `has been assigned the task`. The line is `You **have** been assigned the

2. **P0-2 and P0-3 are NOT dead, and this is the biggest correction.** The
   ruling was that `/dzlisttimers` is a live-EverQuest/EQEmu command that Legends
   does not have. The installed client's own string table
   (`<install>/eqstr_us.txt`, line 1949) carries:

   > `3536 Usage: /dzListTimers - This command will list any outstanding replay
   > timers you have for all expeditions.`

   A string table alone proves nothing — it is inherited Daybreak content

   **But three strings from that same expedition block fire verbatim in our own

   ```

   ```

   **Somebody typed a `/dz` command and the server answered.** The family is
   live. And `grep -F "outstanding replay"` returns **0** — nobody has ever run
   the one command that lists timers. Ten seconds, never spent.

3. **"Do not decode the log as UTF-8" is wrong.** Measured: exactly 9 bytes ≥
   0x80 in 434 MB, all `EF BF BD` (U+FFFD), valid UTF-8. Every cp1252 signature

   right. *Second layer, unsettled:* U+FFFD is itself the residue of a lossy
   decode, so "the client originally emitted UTF-8" cannot be settled from a

### Method, because the shape of the errors is the useful part

**My own instrument manufactured false findings twice, and both were caught only
by running it against the real corpus rather than the fixture.**

- Merging two characters produced a **4-second "reset bracket"**. Fixed by
  requiring a character at construction.
- Terminating the hail exchange on the Voidling's closing line produced a **false
  0.474-hour bracket** — because the closing line can arrive *before* the task
  line. Verbatim, and the reason there is now a test named `THE ORDERING TRAP`:

  ```
  [Tue Aug 11 20:40:44 2026] You say, 'danger'
  [Tue Aug 11 20:40:44 2026] Voidling says, 'Your hubris risks our very reality itself.'
  [Tue Aug 11 20:40:44 2026] You have been assigned the task '... Lady Vox - Weekly'.
  ```
- Then the fix itself over-tightened, producing a **9-second bracket**, because a
  refusal **does not name a boss** and I let refusals count after the new period
  had demonstrably started.

Three self-inflicted false measurements in one session, all found, all now
regression-tested. The lesson is the one this project keeps relearning: **a
detector that has only been run on a fixture has not been run.**
